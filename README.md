# Salenbici 🚲

¡Bienvenido a Salenbici! Esta es una aplicación web diseñada para facilitar la movilidad urbana sostenible mediante el uso de bicicletas públicas. 

Consulta el estado de las estaciones, planifica tu ruta por los carriles bici y mantente informado del tiempo, todo en una interfaz rápida, intuitiva y accesible.

## 🔗 Enlace a la Aplicación
Puedes acceder a la aplicación en tiempo real aquí:
👉 **[www.salenbici.vercel.app](https://www.salenbici.vercel.app)**

## ✨ ¿Qué es Salenbici?
Salenbici es una herramienta pensada para usuarios frecuentes de sistemas de bicicletas públicas que buscan optimizar sus desplazamientos diarios. La web ofrece:

*   **Mapa interactivo:** Visualiza estaciones y carriles bici en tiempo real.
*   **Gestión de favoritos:** Accede a tus estaciones preferidas con un solo toque.
*   **Información meteorológica:** Consulta el clima antes de salir.
*   **Diseño PWA:** Instala la web en tu móvil como si fuera una aplicación nativa.

## 🛠️ Sobre el Proyecto
Este proyecto ha sido desarrollado con tecnologías web modernas enfocadas en la experiencia de usuario (UX) y el rendimiento. El objetivo principal es ofrecer una solución limpia y eficiente para la consulta de datos de movilidad municipal.
